# People Overlay AI — CCTV v1.7 (Capture + Clean Tracking)

Автономный экранный детектор людей с четырьмя угловыми маркерами поверх RVi Operator, без подключения к регистратору. Целевые платформы: Windows 7–11 (x64/x86). Python и интернет на рабочем ПК не требуются.

## v1.7: исправлены дубли рамок и задержка удаления, добавлена диагностика живого видео

- Исправлена ошибка глобального сопоставления ID: алгоритм предпочитал оставить цель неподтвержденной и создать новую вместо привязки к имеющейся. Новые AI-рамки теперь корректно прикрепляются к существующим людям.
- Все уровни YOLO для одного человека (полная фигура, верхняя часть, голова) сравниваются с учетом вложенности, горизонтального центра и расположения в силуэте. **Остаётся один набор уголков**, предпочтение отдаётся полной фигуре.
- Дубли, успевшие возникнуть на соседних зонах, согласуются по ID. При этом два близких человека одинаковых размеров остаются двумя разными целями.
- AI повторно проверяет камеры с уже найденными людьми каждые ~4 секунды при наличии свободного CPU. Две отрицательные проверки удаляют старую рамку. Неподвижный человек не считается исчезнувшим только из-за отсутствия движения.
- В трее появился **«Захват видео: совместимый режим (CAPTUREBLT)»**. На части систем Windows это позволяет захватывать видеослои, которые пропускает обычный BitBlt.
- В трее появился **«Проверить видеокадры (2 снимка за 1,4 сек)»**. Программа сохраняет на рабочий стол два кадра того, что реально видит алгоритм, и показывает в меню процент различающихся пикселей. При движении в видео, но пустом или замороженном кадре на снимках, проблема в захвате, а не в YOLO.
- Файлы диагностики сохраняются **только локально**. Интернет и подключение к IP-камерам программе не нужны.
- Регрессионные тесты воспроизводят фото с несколькими наборами уголков на одном человеке, защиту от склейки двух разных людей, очистку после повторных отрицательных AI-проверок и проверку живых кадров.

**Важно:** CAPTUREBLT не гарантирует получение видео, если RVi использует DirectDraw/Direct3D аппаратный overlay, невидимый для GDI. В этом случае на конкретном рабочем ПК потребуется переключить отрисовку RVi в программный или совместимый режим (если настройка доступна); тест 2 кадров покажет проблему. Автотест NCNN на Windows 2022 не моделирует видеорендерер реального RVi Operator.

## v1.6: исправлено меню трея Windows 7

- Значок трея раньше создавал меню через стандартный класс окна `STATIC`: это элемент управления, который на Windows 7 плохо получает фокус. Значок появлялся, но контекстное меню могло не открываться.
- Теперь зарегистрирован отдельный собственный оконный класс Win32, способный получать фокус; меню открывается на координатах курсора и корректно освобождает фокус при закрытии.
- Правый клик по значку показывает меню. Также для доступа к меню есть `Ctrl+Alt+F8`, для быстрого включения детекции — `Ctrl+Alt+F9`, для звука — `Ctrl+Alt+F7`.
- В v1.6 сохранены все улучшения v1.5 (Person Lock) и звуковая тревога. Перед запуском нового EXE необходимо завершить старый процесс People Overlay AI в Диспетчере задач.
- Сборка тестируется в GitHub Actions на x86/x64. Реальная интерактивная проверка меню в Windows 7 требует ПК оператора.

## v1.5: Person Lock — сопровождение человека

- При нескольких людях их прямоугольники **сопоставляются все вместе** глобальным алгоритмом «один к одному», а не поочерёдным захватом первого ближайшего ID.
- Учитываются траектория, локальная скорость, совпадение формы и положение человека. Два пересекающихся человека сохраняют **разные идентификаторы**.
- Два человека **не объединяются автоматически** лишь из-за наложения прямоугольников. Только почти одинаковые YOLO-предложения считаются дубликатами.
- Человек в спокойной позе с однотонной одеждой сохраняет уголки по неизменности пикселей; даже без заметного перемещения он должен оставаться целью до очередной проверки YOLO.
- Адаптивное сглаживание координат: мелкий дрожащий AI-сдвиг приглушается; быстрый реальный сдвиг подтверждённой цели обрабатывается быстрее.
- Угловые маркеры получили тёмный контур, чтобы оставаться различимыми на светлом видео и в ночном ИК-режиме.
- Автотесты: пересечение и встречное движение людей, независимость двух наложенных рамок, неподвижный человек, отсутствие дублей, сохранение независимости при появлении новых людей.

Точность до пикселя и безошибочная идентичность при полном перекрытии людей невозможны только по YOLOv8n и экранным кадрам. Не используйте программу вместо полноценной охранной системы.

## v1.4: что изменилось

- YOLOv8n (person) и NCNN, по умолчанию один AI-поток.
- Последовательный анализ 2×2, 3×3 или 4×4 зон (до 16 видеокамер); автоматическая адаптация к разрешению.
- Подготовка 640×640 для AI теперь вынесена из потока захвата экрана в отдельный рабочий поток. Вместо большого RGB-тензора передаётся копия выбранного BGRA-участка.
- Трекинг перемещает уголки между проверками нейросети. При смене всех видеокамер разом устаревшие рамки сбрасываются. После двух отрицательных проверок конкретной зоны ложная рамка убирается.
- Исходный пользовательский сигнал встроен в EXE: короткий (3 импульса) или полный (8), без повторения на каждом кадре. Интервал 15/30/60 секунд, дополнительно 90 секунд в той же видеозоне.
- Звук можно включать и отключать через трей и Ctrl+Alt+F7. Выбор сохраняется после перезапуска в `%LOCALAPPDATA%\\PeopleOverlay\\alarm_settings.json`.
- Распознавание работает локально. Снимок экрана создаётся только по ручному запросу в трее.

## Управление

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+F9 | Вкл./выкл. детекцию |
| Ctrl+Alt+F7 | Вкл./выкл. звук |
| Ctrl+Alt+F8 | Открыть меню трея |
| Ctrl+Alt+F6 | Тест угловых маркеров |
| Ctrl+Alt+1 / 2 / 3 | Цвет маркеров |
| Ctrl+Alt+F10 | Выход |

Правый/левый клик по трею открывает меню. Там есть режим 4×4, чувствительность, контраст, режим двух потоков CPU, пауза/длина сигнала и тест звука.

## Готовые EXE из GitHub Actions

Откройте [Windows NCNN workflow](../../actions/workflows/win7-ncnn.yml) → успешный запуск ветки `fix/live-video-capture-v17` → artifact `PeopleOverlay_v1.7_CCTV_Capture_Tracking_Fix`. Внутри находятся `PeopleOverlay_Win7_NCNN_x64.exe` и `PeopleOverlay_Win7_NCNN_x86.exe`.

**Ограничения:** камеры проверяются последовательно, поэтому на слабом CPU быстрый поиск человека во всех 16 камерах одновременно не гарантируется. CI проверяет загрузку настоящей модели и инференс на Windows Server 2022; стабильность Windows 7 и RVi надо проверить на самом посту. Это не сертифицированная охранная сигнализация.
