# People Overlay AI — CCTV v1.4

Автономный экранный детектор людей с четырьмя угловыми маркерами поверх RVi Operator, без подключения к регистратору. Целевые платформы: Windows 7–11 (x64/x86). Python и интернет на рабочем ПК не требуются.

## v1.4: что изменилось

- YOLOv8n (person) и NCNN, по умолчанию один AI-поток.
- Последовательный анализ 2×2, 3×3 или 4×4 зон (до 16 видеокамер); автоматическая адаптация к разрешению.
- Подготовка 640×640 для AI теперь вынесена из потока захвата экрана в отдельный рабочий поток. Вместо большого RGB-тензора передаётся копия выбранного BGRA-участка.
- Трекинг перемещает уголки между проверками нейросети. При смене всех видеокамер разом устаревшие рамки сбрасываются. После двух отрицательных проверок конкретной зоны ложная рамка убирается.
- Исходный пользовательский сигнал встроен в EXE: короткий (3 импульса) или полный (8), без повторения на каждом кадре. Интервал 15/30/60 секунд, дополнительно 90 секунд в той же видеозоне.
- Звук можно включать и отключать через трей и Ctrl+Alt+F7. Выбор сохраняется после перезапуска в `%LOCALAPPDATA%\\PeopleOverlay\\alarm_settings.json`.
- Распознавание работает локально. Снимок экрана создаётся только по ручному запросу в трее.

## Управление

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+F9 | Вкл./выкл. детекцию |
| Ctrl+Alt+F7 | Вкл./выкл. звук |
| Ctrl+Alt+F8 | Открыть меню трея |
| Ctrl+Alt+F6 | Тест угловых маркеров |
| Ctrl+Alt+1 / 2 / 3 | Цвет маркеров |
| Ctrl+Alt+F10 | Выход |

Правый/левый клик по трею открывает меню. Там есть режим 4×4, чувствительность, контраст, режим двух потоков CPU, пауза/длина сигнала и тест звука.

## Готовые EXE из GitHub Actions

Откройте [Windows NCNN workflow](../../actions/workflows/win7-ncnn.yml) → успешный запуск ветки `feature/cctv-smooth-v14` → artifact `PeopleOverlay_v1.4_Smooth_CCTV_Alarm_Win7to11`. Внутри находятся `PeopleOverlay_Win7_NCNN_x64.exe` и `PeopleOverlay_Win7_NCNN_x86.exe`.

**Ограничения:** камеры проверяются последовательно, поэтому на слабом CPU быстрый поиск человека во всех 16 камерах одновременно не гарантируется. CI проверяет загрузку настоящей модели и инференс на Windows Server 2022; стабильность Windows 7 и RVi надо проверить на самом посту. Это не сертифицированная охранная сигнализация.
