# People Overlay AI

Экспериментальный автономный экранный детектор людей с четырьмя уголками над изображением. Прототип для Windows x86/x64.

## Функции

- Нейросеть YOLOv8n, распознавание **person** по изображению основного монитора, без подключения к камерам и регистратору.
- Один CPU-поток ONNX Runtime, паузы между обработкой кадров, последовательное сканирование четырёх участков экрана.
- Прозрачное окно поверх других программ, без перехвата кликов.
- Ctrl+Alt+F9: включить/выключить, Ctrl+Alt+F6: тест рамок, Ctrl+Alt+1/2/3: цвет, Ctrl+Alt+F10: выход.
- Модель и DLL упакованы непосредственно в EXE. При запуске они извлекаются в LocalAppData без интернета.
- Без Python и обязательной установки компиляторов на пользовательском компьютере.

## Сборка

Откройте [Actions](../../actions/workflows/windows-build.yml) → **Run workflow**. После завершения сборки скачайте artifact **PeopleOverlay_Windows7to11**.

⚠️ Windows 7/8/8.1: лишь целевые платформы, совместимость надо проверить на реальных машинах. Windows 11: сборка на GitHub runner и smoke-test; реальное видеонаблюдение надо проверить отдельно. Детекция одновременно сотен маленьких камер на слабом CPU не гарантируется. Программа не взаимодействует с RVi или видеорегистраторами.
