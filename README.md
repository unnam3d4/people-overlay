# People Overlay AI v3 — Windows 7 / Windows 10

**Экспериментальная версия для реальных испытаний, не стабильный релиз.**

People Overlay выделяет **фигуры людей, а не лица**, четырьмя уголками поверх
видео RVi Operator. Программа не подключается к камерам, регистратору
или сети, не модифицирует RVi. Используется изображение рабочего стола Windows.

## Только Windows

- Целевые системы: **Windows 7 SP1 и Windows 10**, x86 и x64.
- Go 1.20.14, нативный NCNN FP32 CPU; не требуется Python, Интернет, CUDA или GPU на операторском ПК.
- Требуется совместимый CPU; для x86 — SSE2.
- Сборки создаются и проверяются на Windows Server 2022 в GitHub Actions.
  **Это не означает, что запуск на реальном Windows 7 уже протестирован**:
  нужны проверка самой Win7, драйверов, BitBlt и RVi Operator.
- Никакой поддержки иных операционных систем проект v3 не обещает.

## v3: работа с несколькими мониторами

- Автоматически находятся до **четырёх** дисплеев Windows с разным разрешением
  и расположением, включая отрицательные координаты X/Y.
- **Все четыре монитора сканируются**, каждый с собственным кадром, очередью
  зон, трекером и номером поколения сцены.
- Прозрачный слой уголков покрывает их общий виртуальный рабочий стол;
  уголки переводятся из локальных координат в виртуальные.
- Один общий последовательный NCNN CPU worker обслуживает все мониторы,
  чтобы старый i3/i5 не получал четыре постоянно занятых нейросети.
- Проверки распределяются по дисплеям по кругу. Смена сцены на одном экране
  не сбрасывает результаты других. Отказ захвата одного экрана не должен
  блокировать проверку остальных, а старые маркеры очищаются.
- В трее пункт **«Снимок: экран N»** выбирает только экран для локальной
  диагностики, а **не** экран для детекции.
- При изменении топологии дисплеев экранные треки сбрасываются;
  устаревшие результаты AI отвергаются.

**Известные ограничения:** четырёхмониторный RVi на физическом оборудовании
не проверен. Для нескольких мониторов всё ещё используется один backend
BitBlt; режим совместимости CAPTUREBLT не гарантирует доступность любого
GPU-рендеринга RVi. Раскладки 2×2, 3×3, 4×4 и одна камера задаются через
трей, общий профиль на все экраны; нестандартные панели пока автоматически
не калибруются. 48 камер не означают 48 независимых потоков распознавания.

## Управление

| Комбинация | Действие |
| --- | --- |
| Ctrl+Alt+F9 | Детекция включена/выключена |
| Ctrl+Alt+F10 | Выход |
| Ctrl+Alt+F7 | Звук включён/выключен |
| Ctrl+Alt+F8 | Открыть трей |
| Ctrl+Alt+F6 | Проверка уголков |
| Ctrl+Alt+1 / 2 / 3 | Зелёные / красные / оранжевые уголки |

Запуск — **только вручную**, автозапуска нет. По умолчанию номера целей
не отображаются, видны только четыре уголка. Звук — один общий канал
с паузами 15/30/60 секунд и дополнительной защитой от повторов по зоне.

## Точность и требования перед выпуском

Цель пользователя: до **двух секунд** на обнаружение новых людей,
до четырёх мониторов и 48 камер, включая неподвижных, сидящих, частично
закрытых и мелких людей. Это **цель разработки, не подтверждённый SLA**.
На слабом CPU один последовательный AI-worker физически не может
гарантировать нейропроверку всех 48 камер за 2 секунды.

Отчёт [BENCHMARK.md](BENCHMARK.md) относится к тестам **v20**, а не
к доказанному качеству v3. На реальном PETS2009 у v20 наблюдались
серьёзные пропуски; v3 не разрешено считать исправлением, пока не будет
воспроизводимого A/B теста на полностью размеченных фигурах людей.
Тесты `--selftest`, unit-tests и компиляция подтверждают только базовую
работоспособность, а не качество реальной охранной детекции.

Перед стабильным релизом нужны:
1. Проверка на реальных Windows 7 SP1 и Windows 10 с RVi и 1–4 мониторами.
2. P/R и задержки первых обнаружений по реальным body-bbox записям,
   включая отдельные отчёты для 4×4 и 48 камер.
3. Нагрузочные тесты на старых i3/i5 (CPU/RAM) и диагностика реального BitBlt.
4. Исключение регрессий по сравнению с v1.9/v20.

Программу нельзя использовать как единственное средство охранной тревоги.
